🎓 Programa Rededaora — Polo Cangaíba
Plataforma educacional desenvolvida para disponibilização de materiais didáticos do curso de UX + Web Design Empreendedor com IA, ministrado no Polo Cangaíba.

O projeto foi criado com foco em experiência do usuário (UX), criatividade, design, empreendedorismo e uso de Inteligência Artificial, proporcionando uma experiência de aprendizagem simples, acessível e prática, permitindo que as alunas acessem conteúdos diretamente pelo navegador.

🚀 Acesso ao projeto
Após publicado no GitHub Pages:

👉 https://vanessabaldin1.github.io/portal-ux

📚 Funcionalidades
🔐 Tela de login com autenticação simples (sem backend)
📱 Layout responsivo (mobile-first)
📄 Acesso a materiais em PDF
🎧 Podcasts em áudio (M4A/MP3)
🎵 Músicas de fixação de conteúdo
📸 Mural de fotos das aulas
🎬 Mural de vídeos das aulas
🌙 Modo claro/escuro (dark mode)
⬆ Botão de scroll suave para navegação
👩‍🏫 Identificação personalizada do usuário logado
🚪 Botão de logout

🎯 Objetivo do projeto
Criar uma plataforma simples, leve e acessível para alunas acompanharem os conteúdos das aulas presenciais, com foco em:

experiência do usuário (UX)
fundamentos de Web Design
criatividade e desenvolvimento de projetos
empreendedorismo digital
utilização de Inteligência Artificial como ferramenta de apoio
organização de materiais e conteúdos
facilidade de acesso
experiência mobile fluida
incentivo à criação e ao desenvolvimento de novas ideias
